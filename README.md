## 概要

月都の結界を侵食する妖怪型ドローン《穢機》を、結界機《カグラ》で迎撃するブラウザ向けアーケードシューティングです。朱の鬼面、白い狐面、提灯、蛇霊、天狗面をサイバー意匠として再解釈した敵編隊を突破し、月都を守る三つの結界を復旧してください。

MVP版のインベーダーゲームを、**3ステージ・9ウェーブ・3ボス・戦闘進行と同期する背景変化・ボス覚醒フェーズ・結界復旧演出・結界解放・コンボ・難易度選択・難易度別ハイスコア・効果音・設定・モバイル操作UI**を備えた同人ゲーム品質の三結界篇へ刷新しました。

## 難易度設定

タイトル画面で、プレイ経験と目的に応じて難易度を選べます。選択内容は端末内に保存され、ハイスコアも難易度ごとに分けて記録されます。

| 難易度 | 推奨対象 | 主な調整 | スコア倍率 |
|---|---|---|---:|
| **見習い / EASY** | 初見、スマホ操作、アクションに不慣れなプレイヤー | HP 7、敵弾を低速・低頻度化、敵とボスの耐久低下、霊力の早期蓄積 | ×0.75 |
| **守護者 / NORMAL** | 標準的な難度を楽しみたいプレイヤー | 従来のバランスを基準にした敵弾、耐久、ボス弾幕 | ×1.00 |
| **修羅 / HARD** | 弾幕シューティング経験者、ハイスコア狙い | HP 3、高速・高頻度の敵弾、敵・ボス耐久と弾数の増加 | ×1.35 |

> はじめて遊ぶ場合は、**見習い / EASY**をおすすめします。結界解放で敵弾を消す感覚を覚えたら、守護者、修羅へ挑戦してください。

詳細な調整値は[バランス仕様](BALANCE.md)を参照してください。

## 結界修復札: 回復アイテム

通常敵を撃破した際、自機HPが最大未満なら、低確率で**結界修復札 / REPAIR OFUDA**が落ちることがあります。金色の御札に緑の回復紋が目印です。接触するとHPを**1回復**しますが、最大HPを超えることはありません。

| 難易度 | 出現率 | 補足 |
|---|---:|---|
| 見習い / EASY | 12% | 初見プレイヤーの立て直しを助ける。 |
| 守護者 / NORMAL | 8% | 回収を狙う価値はあるが、回避を置き換えない。 |
| 修羅 / HARD | 5% | 緊張感を維持する限定的な救済。 |

画面内の修復札は最大2個までで、回収しない場合は短時間で消滅します。詳細は[回復アイテム設計書](HEAL_ITEM_DESIGN.md)を参照してください。

## 三結界篇: ステージ構成

3つの結界を順番に奪還する通しプレイです。各ステージは3ウェーブと固有ボスで構成され、ボスを倒すと弾幕が整理され、結界障子と霊力を補給したうえで次の景観へ遷移します。

| 章 | ステージ | 背景・色彩 | ボス | 攻略の主題 |
|---:|---|---|---|---|
| 1 | **第一結界 — 朱ノ鳥居** | 藍の月夜、未来神社都市、朱い鳥居、青緑グリッド | 紅月ノヲロチ | 基本の扇状弾と結界解放を学ぶ。 |
| 2 | **第二結界 — 碧ノ水鏡** | 青月、水面反射、灯籠橋、紫のデータ海月 | 蒼渦ノ河童 | 水流弾と渦弾の間隔を読み、横移動で回避する。 |
| 3 | **第三結界 — 黒曜霊峰** | 紅い蝕月、山影、浮遊神社、紅紫グリッド | 天裂ノ八咫 | 多尾弾と放射弾を結界解放とともに攻略する。 |

各章は通常戦闘・ボス警報・ボス登場・覚醒フェーズ・浄化撃破で景観の発光、粒子、結界環、警告帯が変化します。ボスHPが半分になると弾幕を一度整理したうえで**PHASE 02**へ移行し、攻撃速度と弾幕密度が高まります。

> ステージとウェーブはゲーム画面上部の`STAGE 1/3`と`01-01`形式のHUDで確認できます。

詳細な構成は[ステージ設計書](STAGE_DESIGN.md)を参照してください。

## 統一アートの実装

ゲーム中で実際に操作・撃破する対象を、背景と同じネオン和風サイバーSFのアートへ統一しました。自機《カグラ》、鬼面・狐面・提灯・蛇霊・天狗面の敵ドローン、3種の章ボスは、最適化済みの透過PNGスプライトとしてCanvas上へ描画されます。背景・弾幕・障子・粒子は軽量なCanvas描画を維持しているため、視覚品質とブラウザでの軽快さを両立しています。

| 範囲 | 実装 |
|---|---|
| 自機 | 鳥居翼・御札・朱い炉心を持つ結界機《カグラ》スプライト。 |
| 通常敵 | 鬼面、狐面、提灯、蛇霊、天狗面の5種を固有シルエットで描画。 |
| ボス | 紅月ノヲロチ、蒼渦ノ河童、天裂ノ八咫を章ごとの大型スプライトで描画。 |
| 安定性 | 画像読み込みに失敗した場合は、既存のCanvas幾何描画へ自動でフォールバック。 |

詳細な制作基準は[スプライト・アート仕様](SPRITE_ART_SPEC.md)を参照してください。

## 対応環境

HTML5 CanvasとWeb Audioを利用する静的ブラウザゲームです。インストールやアカウント登録は不要で、以下の環境の現行ブラウザを主対象とします。

| プラットフォーム | 対象ブラウザ | 操作 |
|---|---|---|
| Windows / macOS / Linux | Chrome、Edge、Firefox、Safari（macOS） | キーボード |
| Android | Chromeほかの現行Chromium系ブラウザ | 仮想ボタン |
| iOS / iPadOS | Safariほかの現行WebKit系ブラウザ | 仮想ボタン |

> 初回のユーザー操作後に効果音が有効になります。これはモバイル・デスクトップを問わず、ブラウザの自動再生制限に配慮するための仕様です。

## 遊び方

プレイヤーは、式札ショットで敵を倒し、連続撃破によってコンボ倍率を伸ばします。敵を倒すと霊力が蓄積され、満タン時に**結界解放**を使えます。結界解放は敵弾を消去し、広範囲の敵とボスへ大きなダメージを与える切り札です。

各ステージは3ウェーブ構成です。各ウェーブを撃破すると、その結界を侵食する大型ボスが出現します。第一・第二結界のボスを撃破すると、結界障子と霊力を補給して次章へ移ります。第三結界の《天裂ノ八咫》を撃破すると、月都全結界の復旧を記録する最終クリアとなります。プレイヤーHPが0になるか、敵が防衛ラインへ侵入するとゲームオーバーです。

## ローカルでの実行

ソースを取得した後、任意の静的HTTPサーバーで公開してください。ES Modulesを用いるため、`file://`で直接開くのではなくHTTPサーバー経由での起動が必要です。

```bash
git clone https://github.com/tailofyukki-cell/space-invaders-game.git
cd space-invaders-game
python3 -m http.server 8080
```

起動後、`http://localhost:8080/`を開きます。
